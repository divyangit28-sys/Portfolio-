# Divyangi's Design Lab

The portfolio website of Divyangi Tiwari, UX researcher and designer.

This repository is the live site, published with GitHub Pages from the root of `main`: https://divyangit28-sys.github.io/Portfolio-/
Every push to `main` goes live within a minute or two. There is no build step.

## What's here

- `index.html`: the whole page (styles and scripts inline). It mirrors the portfolio page on Claude.
- `projects.json`: data for the three "Projects that made an impact" cards.
- `covers/`: cover images for those cards.
- `pets/`: the pet project images shown in the full-size viewer.
- `work/`: public copies of the case studies the cards open (`emr/`, `f16s/`, `prescribed-services/`), with their images, videos and prototypes. They are snapshots of the Claude versions, so refresh them here after editing a case study.
- `tales/`: cover art for the corporate tales, and `tales/designing-the-wait/`, the full story.
- `resume/`: the downloadable resume PDF.
- `avatar.png`: the logo and browser-tab icon.
- `404.html`: the page shown for addresses that don't exist.
